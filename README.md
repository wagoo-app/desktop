# Wagoo Desktop

**L'application de contrôle et de synchronisation locale pour Wagoo.**

## 🎯 Qu'est-ce que c'est ?

Wagoo Desktop est une application de bureau moderne qui vous permet de :

- ✅ **Scanner des codes QR** depuis vos appareils mobiles
- ✅ **Contrôler votre espace de travail** en temps réel
- ✅ **Recevoir des notifications** instantanées
- ✅ **Synchroniser vos données** automatiquement
- ✅ **Fonctionner hors ligne** si nécessaire

## 🚀 Installation

### Windows & Mac

1. Téléchargez la dernière version depuis [Wagoo.app](https://wagoo.app)
2. Lancez l'installateur
3. L'application démarre automatiquement au démarrage de votre PC

### Linux

```bash
# Installez depuis le package officiel
sudo apt install wagoo-desktop
```

## 📱 Comment utiliser

### Première utilisation

1. **Lancez l'application** → Une icône apparaît dans votre barre des tâches
2. **Cliquez sur l'icône** → La fenêtre principale s'ouvre
3. **Scannez un QR code** avec votre téléphone ou tablette
4. **Confirmez l'action** sur votre appareil

### Fonctionnalités principales

| Fonction | Description |
|----------|-------------|
| 🔄 **Synchronisation** | Vos données se synchronisent automatiquement |
| 🔔 **Notifications** | Recevez les alertes importantes en temps réel |
| 📲 **QR Codes** | Connectez vos appareils en scannant un code |
| 🌐 **Hors ligne** | L'app fonctionne même sans connexion internet |

## ⚙️ Configuration

L'application fonctionne **sans configuration** à partir du démarrage.

Si vous rencontrez des problèmes de connexion :
- Vérifiez votre connexion internet
- Redémarrez l'application
- Contactez le support : [support@wagoo.app](mailto:support@wagoo.app)

## 🔒 Sécurité

- ✅ **Communication chiffrée** avec nos serveurs
- ✅ **Aucune donnée stockée** sans votre consentement
- ✅ **Protocoles modernes** (HTTPS, WSS)
- ✅ **Audité régulièrement** par nos équipes de sécurité

## 📊 Statut et Mises à Jour

L'application vérifie automatiquement les mises à jour et vous le notifie.

Vous pouvez aussi vérifier manuellement :
- **Menu** → Vérifier les mises à jour
- Ou clic droit sur l'icône du tray → Vérifier les mises à jour
